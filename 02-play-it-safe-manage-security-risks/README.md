# Activity: Controls and Compliance Checklist

## Overview
This activity evaluates the current security controls and regulatory compliance posture for **Botium Toys** based on an initial risk assessment report.

## Document
* 📄 [View Full Completed Checklist](portfolio-activity-controls-and-compliance-checklist.pdf)

## Key Recommendations
* **Security Controls Needed:** Implement Least Privilege, Separation of Duties, Data Encryption, and Intrusion Detection System (IDS) to protect sensitive customer data.
* **Compliance Standards (PCI DSS / GDPR / SOC):** Implement data encryption procedures across all transaction touchpoints, restrict credit card access to authorized users, and enforce strict user access and privacy policies.
