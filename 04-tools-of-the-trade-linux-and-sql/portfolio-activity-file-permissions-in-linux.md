# Portfolio Activity: File Permissions in Linux

## Project Description

In this project, I reviewed and applied Linux commands for managing files, directories, software, and file permissions. I focused on understanding file and directory permissions, inspecting permission strings, and modifying permissions using `chmod`.

This project brings together skills practiced throughout the Linux command activities in this course.

[View Full Project Documentation](portfolio-activity-file-permissions-in-linux.pdf)


## What I Practiced

- Inspecting files, directories, and permissions using `ls`, `ls -a`, `ls -l`, and `ls -la`
- Navigating the Linux file system using `pwd` and `cd`
- Understanding Linux permission strings for the owner, group, and others
- Modifying file and directory permissions using `chmod`
- Working with hidden files and directories
- Finding and filtering information using `grep`
- Using pipes (`|`) to pass command output to another command
- Managing files and directories
- Installing and uninstalling software packages using `apt`

## Permission Management

I practiced reading Linux permission strings and identifying the permissions assigned to the owner, group, and others.

For example, I analyzed the permissions of `project_m.txt` and identified the read, write, and execute permissions assigned to each category.

![Check file permissions](./images/activity-7-05-check-file-permission.png)

I then used `chmod` to modify permissions on regular files, hidden files, and directories.
![Change group file permissions](./images/activity-7-06-change-group-file-permission.png)
