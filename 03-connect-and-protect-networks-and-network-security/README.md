# Course 3: Connect and Protect: Networks and Network Security

This section documents my hands-on cybersecurity activities focused on network security, network traffic analysis, system hardening, and incident response.

## Activities

### 1. [Network Traffic Analysis](./activity-1-network-traffic-analysis.md)

Analysis of network traffic to identify suspicious activity and understand network behavior.

### 2. [Network Attack Analysis](./activity-2-network-attack-analysis.md)

Analysis of common network attacks and attack patterns, focusing on identifying threats and understanding potential security impacts.

### 3. [OS Hardening Techniques](./activity-3-os-hardening-techniques.md)

Analysis of operating system hardening techniques used to reduce security risks and improve system protection.

### 4. [Network Hardening Analysis](./activity-4-network-hardening-analysis.md)

Assessment of network security controls and hardening measures designed to reduce vulnerabilities and strengthen network defenses.

### 5. [NIST CSF Incident Response Analysis](./portfolio-activity-nist-csf-incident-response-analysis.md)

Analysis of incident response activities using the five functions of the NIST Cybersecurity Framework: Identify, Protect, Detect, Respond, and Recover.
